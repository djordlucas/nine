# Contributing

**This repository does not accept external pull requests.**

Nine is developed and maintained solely by [@djordlucas](https://github.com/djordlucas).
All changes are made directly by the maintainer.

## Found a Bug?

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Your `nine.toml` configuration (if relevant)
- Logs or error output

## Have a Feature Request?

Open an issue describing the use case. There is no guarantee of implementation.

## Security Issues

**Do not open a public issue.**
See [SECURITY.md](.github/SECURITY.md) for private reporting instructions.

## Self-Hosting / Usage Questions

For usage questions, open a **Discussion** rather than an issue.
